cURL Examples

cURL: Search Posts

curl "https://rgavanp.kdns.fr/blog/api/posts/?search=API"

cURL: Search Comments

curl "https://rgavanp.kdns.fr/blog/api/comments/?search=python"

cURL: Recent 10 Posts

curl "https://rgavanp.kdns.fr/blog/api/posts/" | jq '.[0:10]'

cURL: Recent 10 Comments

curl "https://rgavanp.kdns.fr/blog/api/comments/" | jq '.[0:10]'

cURL: Read One Post

curl "https://rgavanp.kdns.fr/blog/api/posts/1/"

cURL: Read One Comment

curl "https://rgavanp.kdns.fr/blog/api/comments/1/"

cURL: Create Post

curl -X POST "https://rgavanp.kdns.fr/blog/api/posts/" -H "Authorization: Token YOUR_TOKEN_HERE" -H "Content-Type: application/json" -d '{"title":"API Post","slug":"api-post-example-change-this-slug","body":"posted from api","status":"PB","tags":["#api"]}'

cURL: Create Comment

curl -X POST "https://rgavanp.kdns.fr/blog/api/comments/" -H "Authorization: Token YOUR_TOKEN_HERE" -H "Content-Type: application/json" -d '{"post":1,"body":"comment from api"}'

cURL: Edit Post

curl -X PATCH "https://rgavanp.kdns.fr/blog/api/posts/1/" -H "Authorization: Token YOUR_TOKEN_HERE" -H "Content-Type: application/json" -d '{"title":"Updated title from api"}'

cURL: Delete Comment

curl -X DELETE "https://rgavanp.kdns.fr/blog/api/comments/1/" -H "Authorization: Token YOUR_TOKEN_HERE"
